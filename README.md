# Customer Segmentation using K-Means Clustering

## Project Overview
This project performs customer segmentation using the K-Means Clustering algorithm. The goal is to group customers with similar characteristics based on their Age, Annual Income, and Spending Score. Customer segmentation helps businesses understand customer behavior and develop targeted marketing strategies.

## Dataset
- Dataset Name: Mall Customers Dataset
- Total Records: 200
- Total Features: 5

### Features
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Objective
- Perform customer segmentation using K-Means Clustering.
- Identify customer groups with similar characteristics.
- Visualize the clusters using a scatter plot.
- Interpret the characteristics of each cluster.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Explore the dataset.
4. Select relevant features.
5. Standardize the data.
6. Find the optimal number of clusters using the Elbow Method.
7. Train the K-Means model.
8. Assign cluster labels to customers.
9. Visualize customer clusters using a scatter plot.
10. Analyze and interpret each cluster.

## Results
The K-Means algorithm successfully divided customers into five clusters based on Age, Annual Income, and Spending Score. The segmented groups provide valuable insights into customer purchasing behavior and can help businesses improve marketing strategies and customer engagement.
